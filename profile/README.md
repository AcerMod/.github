# Hello there 👋
Welcome to AcerMod! AcerMod is a modification of PenguinMod to run on a very fast JIT compiler!

## What was AcerMod named after?
AcerMod was named after the tech company: [Acer](https://acer.com)!

It has insane features like way, way, WAY more fonts, and a giant library of extensions!!!
